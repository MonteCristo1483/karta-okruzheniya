## Веб-карта (web/, MapLibre GL JS 6)

- 2026-11-11 — Воркер MapLibre копируется в `web/public/maplibre-gl-worker.mjs` (скрипт `scripts/copy-maplibre-worker.mjs` через predev/prebuild), в коде `maplibregl.setWorkerUrl(...)` — ни Turbopack, ни webpack не резолвят динамический URL воркера maplibre v6 («Worker failed to load»), штатный API перекрытия пути — единственный надёжный фикс.
- 2026-11-11 — `fill-extrusion-opacity` не поддерживает data-выражения (style spec) — затемнение невыбранных зданий делается через `fill-extrusion-color` + feature-state (цвет приглушается), а подсветка обводкой — через line-слои, где feature-state в opacity работает.
- 2026-11-11 — `queryRenderedFeatures` принимает точку только как массив `[x, y]` (или Point); объект `{x, y}` молча игнорируется и запрос возвращает все фичи — при тестах давало ложные «1172 попадания» и часы отладки.
- 2026-11-11 — Архитектурное правило выбора: состояние выбора здания — в React (`useState<SelectedBuilding>`), подсветка/затемнение — через feature-state на слое (promoteId по `properties.id`), один проход по всем id при смене выбора. Без фильтров по id и без дублирования слоёв.
- 2026-11-11 — Внешний контейнер шторки — `pointer-events-none`, `pointer-events-auto` только у карточки — иначе боковые поля нижней полосы на широком экране перехватывают клики и «пустой клик» не снимает выбор.
- 2026-11-11 — flyTo с `padding.bottom = высота шторки + 24` (высота меряется после отрисовки шторки, двойной rAF) — иначе выбранное здание центрируется под шторкой и не видно; при деселекте padding сбрасывается.
- 2026-11-11 — POI и красные зоны на карте — DOM-маркеры (maplibregl.Marker), не symbol-слои: у нас нет glyphs-хоста (подложка-тайлы не подключены), текст на карте без glyphs не рендерится; меток ~200, производительность ок.
- 2026-11-11 — «Маршруты» до ближайших POI — прямые линии по воздуху, настоящие изохроны/маршруты — после Valhalla (скоринг тоже ждёт его; конфиг заморожен).
- 2026-11-11 — Баг глубины в `eachPosition` (geo-utils): MultiPolygon требует depth 3 (polygons→rings→positions), а не 2 — координата здания считалась [NaN, NaN] (truthy, поэтому тест «ok: 3306» врёт — NaN-массив проходит проверку); молча ломало flyTo, центры зданий, пины и маршруты. Проверяй числа, не truthiness.
- 2026-11-11 — TypeScript 7 (tsgo) в веб-карте: `new Map<K, V>()` (глобальный) ломается с TS7009/TS2558 — используем Record вместо Map.
- 2026-11-11 — Вьюхи PostGIS с `SELECT *` не подхватывают колонки, добавленные ALTER TABLE позже — нужен CREATE OR REPLACE VIEW (поймали при добавлении poi.subtype).
- 2026-11-11 — maplibre v6: внутренности источника не доступны (`getSource('routes')._data` нет); для проверок данных в тестах — `querySourceFeatures` (с учётом дублей фичей по тайлам).
- 2026-11-11 — Тёмная тема (M5a): CSS-токены в globals.css + `@custom-variant dark` на `[data-theme="dark"]`; палитры WebGL-слоёв — в TS (MAP_THEMES) и применяются через `setPaintProperty` при переключении (CSS в canvas не достать). Антифлеш — `next/script` beforeInteractive + `suppressHydrationWarning` на <html>, а состояние темы в React стартует со стабильного «light» и синхронизируется с localStorage после монтирования — иначе гидрационный mismatch (SSR не знает localStorage).
- 2026-11-12 — Баг мобильного canvas: на OnePlus 15R (Chrome и Firefox) контейнер карты в DOM есть, а canvas нет, консоль и сеть чистые — Next.js dev молча глотал падение при монтировании. Решение: харденинг инициализации (retry на fetch GeoJSON, try/catch вокруг `new maplibregl.Map` с баннером fatal-ошибки, `map.on("error")` → console) + Error Boundary вокруг карты; проверка в прод-режиме (`next build && next start`) — на телефоне canvas появился, карта работает. Диагностические console.log из эффекта убраны, Boundary оставлен как страховка.
- 2026-11-12 — M5b, статический экспорт на GitHub Pages: `output: "export"` + `distDir: "dist"` + `basePath: "/karta-okruzheniya"` (сайт живёт в подпапке репозитория). Все fetch-URL GeoJSON и `setWorkerUrl` переведены на относительные пути — абсолютные сломались бы за пределами basePath. Dev теперь тоже на /karta-okruzheniya/. `next start` с экспортом не работает — скрипт убран.
- 2026-11-12 — `npx serve` под Windows непригоден для проверки: 404 на существующие файлы, 500 на JS-чанки, 308 со срезанием слэша. Локальная проверка Pages-раскладки — `scripts/serve-test.mjs` (копия dist в .pages-test/karta-okruzheniya имитирует репозиторий в Pages).
- 2026-11-12 — Кнопка «Отправить клиенту»: navigator.clipboard есть только в secure-контексте (https/localhost) — на http://192.168.* автокопирование падает, поэтому fallback-блок с ручным копированием ссылки не опция, а обязательная ветка (проверена принудительным отключением clipboard в тесте).
- 2026-11-12 — GitHub Pages отдавал 404 на `_next/static/*` даже с корректным basePath: Pages по умолчанию гоняет Jekyll, а Jekyll не публикует пути с подчёркиванием. Решение: `.nojekyll` в корень деплоя (`gh-pages -d dist --nojekyll`). Плюс `assetPrefix = basePath` — без него Turbopack оставляет часть ссылок на чанки абсолютными (`/_next/...`), которые в подпапке Pages бились бы 404. Диагностика: `Last-Modified` index.html показывает, какая сборка Pages активна — сверять с временем пуша в gh-pages.
- 2026-11-12 — M7: начальная видимость слоёв (DEFAULT_VISIBILITY) применяется только через applyVisibilityRef — без явного вызова на load чекбокс «выкл», а слой рисуется. Вызов applyVisibility на map load обязателен.
- 2026-11-12 — M7: «прямые по крышам» заменены на квадратичные Безье (контрольная точка сбоку от середины, сэмплинг в 25 точек) + line-dasharray [4,4]; длинные прямые сегменты на extrusion-карте выглядят как линии через крыши.
- 2026-11-12 — M7: мягкая тень зданий — второй fill-extrusion слой с fill-extrusion-translate [1.5,1.5] и opacity 0.1 под основным; на мобильном (<768px) выключается через matchMedia + setLayoutProperty (производительность).
- 2026-11-12 — M7: мобильная шторка — высоты 45dvh/85dvh/92px со snap-переходами (transition-[height,transform]), свайп по ручке меняет snap; в минимальном виде контент скрыт через CSS (md:hidden / hidden), десктоп остаётся auto-по-контенту.
- 2026-11-12 — M7: иконка favicon — link rel="icon" на SVG через metadata.icons (app/icon.svg route удалили в M6, без metadata браузер запрашивает /favicon.ico → 404).

- 2026-11-13 — FX-1: маршруты фильтруются по видимости слоя категории (BONUS_TO_LAYER: transport→metro и т.д.) — rebuildOverlays клал в источник routes все 5 категорий независимо от чекбоксов, роут к POI выключенного слоя оставался на карте.
- 2026-11-13 — FX-2: цвет зданий — градиент (`interpolate linear`) со стопами по квантилям загруженных индексов (q10→низкий, медиана→нейтральный, q90→высокий), а не step 5/7. Стопы считаются на клиенте из загруженного geojson — конфиг скоринга и пайплайн не тронуты, цвет остаётся презентацией. Фолбэк на старый step, если индексов <10.
- 2026-11-13 — FX-2b, откат градиента: линейная RGB-интерполяция пастелей даёт выцветшие промежуточные тона — карта стала ещё бледнее. Заменено на 5 квинтильных ступеней (~20% зданий на цвет): терракот → tan → беж → шалфей → зелень, пороги q20–q80 считаются на клиенте. Урок: для пастельной палитры «градиент» не работает, только дискретные насыщенные ступени. Деплой df5a6f8.
- 2026-11-13 — FX-3: «белые тела + цветные рваные кромки» зданий на десктопе — z-fighting двух экструзионных слоёв одной высоты: теневой `buildings-shadow` из M7 (translate [1.5,1.5], opacity 0.1) на DPR 1 перекрывал основной слой почти невидимой плёнкой, цвет проглядывал только по смещённой кромке. На телефоне слой был выключен — отсюда «на телефоне приятнее». Слой удалён целиком (телефон доказал эстетику без него), ж/д-линии вынесены в отдельный слой `redzones-rail` (width 1.5, opacity 0.45, dasharray [3,3]) — `line-dasharray` не поддерживает data-выражения, поэтому два слоя с фильтрами по `kind`. Проверено скриншотом из встроенного браузера после деплоя (2f9b876) — десктоп рендерится как телефон.
