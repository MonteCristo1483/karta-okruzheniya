# METHODOLOGY V2 — черновик 26.11.2026

Свод двух независимых исследований (шум/воздух; дом/двор/доступность) в одну методологию.
Формула живёт только в `config/scoring.json`; изменение чисел = конфиг + обновление тестов.

## Принципы

1. В балл входит только то, что считается из наших данных с известной грубостью.
2. **Нет данных → 0 штрафа + пометка «не классифицировано».** Никогда не средний штраф.
3. Никаких псевдоточных единиц: не «53 дБ», а «магистраль 1-го класса в 40 м».
4. Каждый фактор объясняется одной фразой в карточке и имеет предельный вклад.
5. Пороги — из стандартов, а не из головы: WHO 2018/2021, Директива 2002/49/EC, СанПиН 1.2.3685-21, СанПиН 2.2.1/2.1.1.1200-03, СП 42.13330.

## Что входит в балл

| # | Фактор | Данные | Формула | Цена |
|---|---|---|---|---|
| 1 | **Близость транспорта** (заменяет «шум») | класс дороги, расстояние | `w_class · max(0, 1 − d/R)^1.5`, R: trunk 250 / primary 150 / secondary 100 / tertiary 60 м | 0, данные есть |
| 2 | **Промышленный источник** | объект (не полигон), класс I–V | радиус СЗЗ по классу: 1000/500/300/100/50 м; штраф `w · (1 − d/R)^1.5`; `d > R → 0` | 1 сессия |
| 3 | **Зелень** | парки ≥0,5 га | бонус, если парк ≥0,5 га в 300 м (WHO) | 0, данные есть |
| 4 | **Дом** | год, серия, материал | под-индекс: панель до 1970 / панель 1970–1990 / кирпич-монолит 1990+ / новостройка; капремонт не подтверждён → нейтрально | 1 сессия на правило + golden |
| 5 | **Плотность** | footprints × этажность | жилая площадь/га в радиусе 150 м | 0 |

**Классификация промзон (ключевое изменение).** Штрафует не `landuse=industrial`, а объект: (а) ручной список крупных источников (ТЭЦ, МНПЗ, мусоросжигательные — 20–40 объектов) с классом по СанПиН 2.2.1/2.1.1.1200-03; (б) автосопоставление с открытым реестром НВОС (onvos.rpn.gov.ru) по координатам; (в) OSM-полигон — только основа. Следствие для примера владельца: гараж/склад/автосервис ≤5 постов = класс V (50 м) → **на 190 м штраф 0**, а ТЭЦ на газе = III (300 м) → штраф есть.

## Только текстом в карточке (в балл не входит)

- **Шум в дБ** — нет данных о потоке (AADT по Москве закрыт), Lden не посчитать; OSM `lanes` занижает. Показываем «магистраль X, 40 м».
- **Инсоляция** — нет окон и ориентации квартиры; норма 2 ч (СанПиН 1.2.3685-21) неприменима к дому без окон. Максимум — «фасад выходит на…», и то при наличии данных.
- **Парковка** — отдельный бейдж «мест на квартиру» с пометкой неполноты OSM (`capacity` есть не везде).
- **Воздух** — качественная полоса вклада трафика (низкий/средний/высокий) по затуханию NO2 в первые 50–150 м; абсолютные мкг/м³ не показываем.
- **Капремонт/аварийность** — «капремонт не подтверждён», перечня работ в машиночитаемом виде нет.

## Ветер со стороны источника (v3, отдельный фактор)

Считается без модели рассеивания и без фиктивных концентраций:
`wind = Σ по источникам I–III класса: w_class · (1 − d/R)^1.5 · P(ветер от источника к дому)`,
где `P` — повторяемость ветра нужного румба из таблицы Росгидромета (Москва, 8–16 румбов, годовая и по сезонам).

- Утверждение в карточке: «ТЭЦ в 900 м на юго-западе, ветер со стороны ТЭЦ на дом ~14% времени».
- Запрещено: концентрации в мкг/м³, «травят газами», любые медицинские формулировки.
- Новые данные: одна таблица ветров (открытая) + список источников из классификатора промзон. Платных данных не требуется.
- Цена: 1 сессия `pipeline` + 1 сессия `web` (компас и объяснение).
- Ограничение: высота трубы и скорость выброса неизвестны → вклад учитывается как «направление и частота», не как «доза».

## Не делаем и почему

- Lden/Lnight в дБ по домам — фиктивные цифры = юридический риск (прецедент: критика эко-карты Яндекса).
- Часы инсоляции по квартире — нет окон/ориентации, высоты из `levels×3` дают до 30% ошибки.
- Воздух по станциям Мосэкомониторинга — станций мало, привязка к дому ложная.
- ART/стресс, «когнитивная нагрузка» в балле — только объяснение текстом.
- СЗЗ как полигоны — в ЕГРН/НСПД, выгрузка платная; ограничиваемся классами и радиусами.

## Веса (решение владельца)

Предложение по умолчанию: транспорт 30%, промзоны 25%, зелень 20%, дом 15%, плотность 10%.
Альтернатива «для арендатора»: транспорт 35 / промзоны 25 / зелень 20 / дом 10 / плотность 10.

## План внедрения

1. `config/scoring.json` → схема v2 (5 факторов, `unknown = 0`, предельные вклады) + golden-тесты (1 сессия `pipeline`).
2. Классификатор промзон: ручной список + НВОС + правила OSM (1 сессия `pipeline`).
3. Карточка: причины из нового `breakdown` (1 сессия `web`, это и есть M1).
4. Пересборка `buildings.pmtiles` + `data.zip` — один деплой на все три шага.

## Открытые вопросы

- Веса и порог «дом» — за владельцем.
- Нужен ли реестр НВОС (парсинг + сверка) или хватит ручного списка 20–40 объектов на старте (рекомендация: ручной список, НВОС позже).
