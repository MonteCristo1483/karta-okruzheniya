# Задача HOMES-V2: вернуть потерянные жилые дома Москвы (~35 тыс.) и отделить нежилой фон

Дата: 2026-11-25.
- **Часть 1 (Пайплайн классификации `is_home`): модель DeepSeek V4.1 Flash (`opencode-go/deepseek-v4.1-flash`).**
- **Часть 2 (Визуальное отделение нежилых зданий от жилых на карте): модель Gemini 4 Argon (`opencode-go/gemini-4-argon`).**

## Контекст

Сейчас в `config/buildings.json` стоит `"require_address": true`: здание считается жилым только при наличии `addr:street` и `addr:housenumber` на самом полигоне в OSM. Из-за этого **35 402 здания в Москве**, у которых есть привязанный жилой паспорт ГИС ЖКХ (`building_year_match`) или явный жилой тег OSM (`apartments`, `residential`, `house`, `detached`, `dormitory`, `terrace`), помечены как `is_home = false`. Пользователь кликает по реальным жилым домам и получает плашку «Нежилое здание».

Кроме того, нежилые здания на карте визуально слишком похожи по контрасту на жилые, из-за чего до клика непонятно, какое здание жилое, а какое нет.

## Часть 1 — Пайплайн (`config/buildings.json`, `pipeline/buildings_filter.py`)

1. В `config/buildings.json` и `pipeline/buildings_filter.py`:
   - Добавить список `"home_building": ["apartments", "residential", "house", "detached", "semidetached_house", "terrace", "dormitory"]`: такие здания считать `is_home = true` даже без `addr:housenumber` на полигоне (если нет явного `non_home_tags`).
   - В PostGIS при обновлении `buildings.is_home` по Москве: если здание не входит в `non_home_building` / `non_home_tags` и имеет привязанный жилой паспорт в `building_year_match` (`distance_m <= 35`), считать его `is_home = true` (и подтягивать адрес из `building_years.address`, если в OSM адрес на полигоне пуст).
2. Добавить unit-тесты в `pipeline/test_buildings_overrides.py`.
3. Пересчитать `scores`, маршруты/изохроны (только для новых `is_home`, которых ещё нет в таблице `routes` — резюмируемо!), обновить `districts/*`, `index.json.gz` и `buildings.pmtiles`.

## Часть 2 — Визуал (`web/app/map.tsx`, модель `Gemini 4 Argon`)

1. Сделать нежилые здания (`is_home == false`) спокойным низкоконтрастным макетным фоном (приглушённый матовый тон крыши и стен без оконной сетки, чуть ниже контраст к земле), чтобы цветные жилые дома (`is_home == true`) с крышами индекса и окнами сразу считывались глазами как интерактивные герои сцены.
2. Поведение клика по нежилому зданию **сохранить**: клик по нежилому зданию по-прежнему показывает плашку «Нежилое здание. Индекс окружения считается только для жилых домов» (без автопрыжка на соседний дом).
3. Снять 3 контрольных кадра DPR1 (`z14.5`, `z16.6` light/dark) для приёмки владельцем.
