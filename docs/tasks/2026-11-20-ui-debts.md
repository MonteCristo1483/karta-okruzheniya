## Задача A. Кнопки зума не должны прятаться под карточкой
На десктопе карточка дома (`md:right-4 md:inset-y-4 md:w-[clamp(340px,38vw,420px)]`,
z-10) закрывает `NavigationControl` в правом верхнем углу карты — при
открытой карточке кнопки `+`/`−` не видны и не кликаются (и на 768, и на
1290). На мобиле всё нормально, там шторка снизу.

Сделать: при открытой карточке на `md+` сдвигать контейнер контролов влево
от карточки. Рекомендуемый минимальный путь:
- в корень шторки в `building-sheet.tsx` добавить атрибут вида
  `data-sheet={building ? "open" : "closed"}`;
- в `globals.css` добавить правило с `:has`, чтобы не трогать React-логику:
  ```css
  @media (min-width: 768px) {
    html:has([data-sheet="open"]) .maplibregl-ctrl-top-right {
      right: calc(clamp(340px, 38vw, 420px) + 1.5rem);
      transition: right 200ms ease-out;
    }
  }
  ```
Ширины/порядок `clamp(...)` обязаны совпадать с карточкой в
`building-sheet.tsx` — если расходятся, кнопки либо налезут на карточку,
либо улетят слишком далеко.
Другой способ допустим, если он не меняет логику карты и выбора дома.

Критерий A: при открытой карточке на 768 / 900 / 1024 / 1290 кнопки зума
полностью видны, не перекрыты и кликаются (проверить клик `+` и `−` и
изменение zoom). Кнопки не наезжают на панель слоёв слева. При закрытой
карточке контролы на прежнем месте.

## Задача B. Контраст неактивных чипов в тёмной теме
Сейчас неактивный чип: `bg-white/55 text-slate-500 dark:bg-slate-900/45
dark:text-slate-400` — на тёмной карте текст и кружок читаются плохо.

Сделать (только тёмная тема, светлую не трогать):
- чип: `dark:bg-slate-900/70 dark:text-slate-300`;
- неактивный кружок: `dark:border-slate-500 dark:bg-slate-800/80`.
Без неона и ярких обводок (SPEC §4), активный чип и зелёная галочка не
меняются.

Критерий B: на тёмной карте текст «Магазины» и «Маршруты» читается без
прищуривания, активные чипы выглядят как раньше.
