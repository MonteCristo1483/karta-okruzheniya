# Задача V-RZ: дороги по зумам и свечение красных зон без blur

Дата: 2026-11-24. **Модель: Gemini 4 Argon, effort High.**
Полоса: `web/app/map.tsx`. Данные, пайплайн, карточку, скоринг не трогать.
Предусловие: BM-1 влит (в тайлах подложки есть `roadclass`).

## Контекст

1. Обзор z10 держит 15 FPS: стиль рисует все дороги класса `major`
   (motorway…tertiary) с обводкой по всей Москве.
2. Владелец: красные зоны после оптимизации стали «редкие, блеклые,
   непонятно прогруженные». Причина: на z11–12 остались только trunk и ж/д,
   а blur включается только с z15.

## Что сделать

### 1. Дороги подложки по зумам (используя `roadclass`)

- z < 10: только `motorway`, `trunk` (одна линия, без casing);
- z 10–11: + `primary`;
- z 12–13: + `secondary`, `tertiary`;
- z ≥ 14: + `residential`, `unclassified`, `living_street` (как сейчас
  minor);
- casing (обводка) — только с z12; до этого одна линия.
- Ширины — сохранить текущие значения там, где класс уже рисовался.

Цель: на z10 в кадре в разы меньше сегментов, обзор плавный.

### 2. Красные зоны: свечение без blur

- Убрать `line-blur` (дорогой) и заменить на **две линии**: широкая
  полупрозрачная (ореол, opacity 0.10–0.14) + узкая яркая (ядро 1.5–2 px).
  Цвета — текущие (`redzone`).
- Показывать зоны с z12 (не с z11): z12–13 — trunk + railway + primary,
  z14+ — все классы.
- На z16.6 внешний вид должен быть близок к прежнему «красивому»: яркое
  ядро, мягкий ореол, без «блеклости». Blur не возвращать.
- Заполнение зон (fill) — как сейчас, только с z13.

## Что нельзя

- Менять данные, тайлы, пайплайн, POI-правила, карточку, скоринг.
- Возвращать `line-blur` (это и был источник тормозов).
- Менять вид зданий, выбранного дома, панель слоёв.
- Добавлять зависимости.

## Проверка

- `tsc`, build, e2e.
- `?perf=1`: z10 — FPS/p95 (ожидание: заметно лучше 15/366);
  z13 — зоны видны; z16.6 — паритет по зданиям.
- Кадры DPR1 light: z10 (только магистрали), z12 (primary+ж/д),
  z13.5 (все зоны, новый ореол), z16.6 (зоны как раньше).
- Один кадр dark z16.6 — ореол не «светит» лишнего.

## Критерий приёмки

1. На z10 нет дворовых улиц и casing; обзор плавный.
2. Красные зоны с z12, выглядят ярко и цельно, без blur.
3. z16.6: здания/окна/выбранный дом без изменений; зоны не хуже прежних.
4. `tsc`, build, e2e; дифф только в `web/app/map.tsx`.

## Стоп-условия

- Без blur ореол выглядит «двойной линией» и не читается — одна поправка
  ширины/прозрачности, затем стоп и отчёт.
- Нужны правки данных — стоп.
- 90 минут.
