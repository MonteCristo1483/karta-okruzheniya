# Задача V4b5: починить контур выбранного дома (hero-окна)

Дата: 2026-11-21. Блокер после V4b4 (#115). Hero-окна работают не для всех
домов: при прямом переходе по ссылке и после смены выбора выделяется
обрезанный «плавник» вместо дома, окон на нём не видно.

## Воспроизведение (проверено на проде)

1. Открыть
   `https://montecristo1483.github.io/karta-okruzheniya/?building=64091248`
   («Никитский бульвар, 25»).
2. На z16.6 и z18 выделен тонкий клин с зелёным контуром; окон нет.
   В источнике `selectedWindows` при этом 225 фич, `queryRenderedFeatures`
   отдаёт 225 — то есть окна строятся, но не на видимой грани.
3. Для сравнения `?building=64091236` («Тверской бульвар, 3/1») — 426
   фич, окна видны. То есть база работает, ломается конкретный дом.

## В чём причина (гипотеза, проверить)

`captureSelectedBody` берёт «наиболее полный неразрезанный контур» одного
тайла. Крупный дом режется границей тайла PMTiles: в загруженном тайле
лежит только клин, остальные части — в соседних тайлах. В итоге footprint
= клин, нормали/смещение окон уходят внутрь или на невидимую грань, а на
видимой стене окон нет.

## Задача

1. **Собирать все части дома.** При захвате брать все фичи с тем же `id`
   из всех загруженных тайлов источника (не «самую полную одну»), и
   объединять их в один footprint (union; порядок колец и дыры сохранить).
   Если часть ещё не загружена — дождаться `sourcedata`/`idle` и
   пересобрать окна один раз, без мигания и без «призраков».
2. **Санитарная проверка.** Если суммарная площадь захваченного контура
   подозрительно мала (например, меньше ~150 м² для дома с 5+ этажами),
   окна не строить вовсе и написать в консоль предупреждение — лучше без
   окон, чем окна на обрезке.
3. **Проверить нормали.** Окна должны стоять на наружной грани, а не
   внутри дома. Для отладки временно покрасить окна в маджента и снять
   кадр с телом и без тела дома; в финале цвет вернуть.
4. **Не ломать:** Тверской 3/1 (64091236) — 426 окон, как сейчас; смена
   дома кликом, тема, зум-порог 15.4, клики по карте.

## Чего не делать

- Не менять данные, тайлы, scoring, карточку, палитру ступеней.
- Не подменять геометрию выдуманной (буферы, прямоугольники «на глаз»).
- Не строить окна для всех домов.

## Проверка

- `?building=64091248`: на 16.6 и 18 окна видны на наружной стене, форма

## Критерий приёмки

Оба дома из проверки показывают окна на видимых фасадах, контур целый,
после смены выбора и перезагрузки по прямой ссылке артефактов нет.
Таймбокс — 45 минут; если union не даётся за это время — отчёт с точной
причиной и вариантами, без костыля «на глаз».
