# Задача BM-1: настоящий класс дороги в тайлах подложки

Дата: 2026-11-24. **Модель: DeepSeek V4.1 Flash.**
Полоса: `pipeline/build_basemap.py`. `web/app/` не трогать, релиз не грузить.

## Контекст

Обзор z10: **15 FPS, p95 366 мс**, при этом красных зон, домов и POI в кадре
нет. Причина в подложке: в тайлах дорога размечена как `major`/`minor`,
а в `major` свалены motorway/trunk/primary/secondary/tertiary (7 типов).
На z10 рисуются все «major» по городу с обводкой — десятки тысяч сегментов.

Нужен исходный класс, чтобы стиль мог показывать на обзоре только
магистрали, а остальное — с z12–14.

## Что сделать

1. В `build_basemap.py` добавить свойству дороги `roadclass` = исходное
   значение `highway` (motorway, trunk, primary, secondary, tertiary,
   residential, unclassified, living_street, service, pedestrian, …).
   Существующее `class` (major/minor) **сохранить** — стиль использует его
   как fallback.
2. Пересобрать `data/basemap.pmtiles` (и geojson, если скрипт пишет оба).
   Настройки tippecanoe не менять.
3. Проверить, что `roadclass` реально попал в тайлы: декодировать один тайл
   z10 (tippecanoe-decode) и показать 5 строк с roadclass; либо отчёт по
   распределению классов.
4. Замеры размеров z8–11 тем же `node web/scripts/tile-size.mjs` — размеры
   не должны вырасти больше чем на 10%.
5. Собрать `data.zip` (структура `data/...`), **не загружать**. Старый
   сохранить как `data.zip.pre-bm1`.

## Что нельзя

- Менять `web/app`, стиль, фильтры, скоринг, здания, маршруты.
- Менять tippecanoe-настройки и лимиты.
- Загружать релиз, деплоить.

## Критерий приёмки

1. В тайлах есть `roadclass`; `class` не потерян.
2. Размеры z8–11 выросли ≤10%.
3. 82 теста зелёные; дифф только в `build_basemap.py`.

## Отчёт (≤15 строк)

1. PR/commit/diffstat.
2. Пример 5 дорог: highway → roadclass → class.
3. Размеры z8–11 до/после, размер basemap.pmtiles и data.zip.
4. Риск строкой.
