# Задача Perf-1: проявление тайлов, кэш, эффекты, перф-оверлей

Дата: 2026-11-24. **Модель: DeepSeek V4.1 Flash.**
Полоса: `web/app/map.tsx`. Данные, тайлы, пайплайн не трогать.

## Контекст

Карту дёргает «кусками». Причины в клиенте:
- MapLibre по умолчанию проявляет каждый тайл за 300 мс — при 20 тайлах
  получается «всплытие» по одному;
- на z14–15 включены три слоя теней и деревья — каждый дом рисуется
  четыре раза;
- кэш тайлов по умолчанию мал, при движении туда-обратно тайлы грузятся
  заново.

## Что сделать

1. **`fadeDuration: 0`** (или 80, если 0 даёт мерцание) в конструкторе
   `maplibregl.Map` — тайлы появляются сразу, без «всплытия».
2. **`maxTileCacheSize: 512`** (подобрать по памяти телефона, начать с 256) —
   меньше повторных загрузок при движении.
3. **Эффекты по зумам**: тени (`buildings-shadow-1..3`) — только с z16;
   деревья — только с z15. На z16.6 — паритет, тени на месте.
4. **Перф-оверлей `?perf=1`**: маленький div поверх карты с FPS (rAF),
   p95 кадра, числом загруженных тайлов и байтами (PerformanceObserver /
   `performance.getEntriesByType('resource')`). В обычном режиме выключен,
   на прод-вид не влияет.
5. Ничего не менять в POI, карточке, палитре, выбранном доме, наклоне.

## Что нельзя

- Менять данные, тайлы, пайплайн, деплой, `/r/`.
- Трогать мобильные настройки (antialias/DPR) — отдельно.
- Добавлять зависимости.

## Проверка

- `tsc`, `npm run build`, `npm run e2e`.
- Локально: `?perf=1`, пройти z11 → z13 → z14 → z15 → z16.6, снять FPS/p95
  и байты в отчёт.
- Два кадра z16.6 light/dark DPR1 — паритет (тени на 16.6 есть).
- Убедиться, что при движении туда-обратно тайлы не запрашиваются повторно
  (сетевой лог).

## Критерий приёмки

1. Тайлы не «всплывают»: появление мгновенное (или ≤80 мс).
2. На z14–15 нет теней и деревьев; на z16.6 они есть.
3. Повторное движение по тому же месту — 0 новых запросов тайлов.
4. `?perf=1` показывает FPS/p95/байты; в отчёте цифры по зумам.
5. `tsc`, build, e2e; дифф только в `web/app/map.tsx`.

## Стоп-условия

- `fadeDuration: 0` даёт заметное мерцание — 80 мс и одна поправка, потом стоп.
- Кэш 512 роняет телефон по памяти — 256.
- 60 минут.
