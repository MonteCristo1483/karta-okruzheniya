   и складывать их в `percentiles: { road, railway, construction, industrial }`
   (пропускать `null`).
2. Для выбранного дома в режиме тайлов брать `percentiles` из метаданных,
   а не считать по `penaltyDistances` (в тайлах распределения нет).

3. Если перцентилей нет — строка скрывается, как сейчас (не подставлять 0).
4. Порог: типы `BuildingMeta` расширить, не глушить `tsc` через `any`.
