# Задача V4b4: hero-окна выбранного дома

Дата: 2026-11-21. Шаг 2 пути B. После V4b3 обычные дома — чистые фасады
и редкие огни. Теперь выбранный дом должен выглядеть как в
`design/card-dark-neon.png`: настоящие окна по фасадам, часть горит
янтарём, часть тёмная, мягкий ореол. Взгляд пользователя и так на нём.

## Что уже есть (использовать, не дублировать)

- Источник `selectedBuilding` и слой `buildings-selected-body` уже
  захватывают footprint выбранного дома из тайлов/geojson при выборе.
  Геометрию брать оттуда, 3 306 домов не дублировать.
- Высота дома — в `buildings-index.json` (`height`), там же `id`.
- Окна обычных домов — из V4b3, их не трогать.

## Задача

1. **Оконная сетка по фасадам выбранного дома.**
   - Для каждого ребра полигона длиной ≥3 м: шаг по фасаду 2.4–3.0 м,
     окно 1.2–1.6 м шириной, 1.6–1.9 м высотой, отступ 0.2 м от углов.
   - Этаж 2.8–3.2 м; первый этаж — от 1.0 м; число этажей =
     `floor((height − 1.0) / 3.0)`, но не больше 30. Окна не выходят
     за крышу.
   - Нормаль наружу — по ориентации кольца (shoelace); окна ставятся
     с наружной стороны, иначе они окажутся внутри дома.
   - MultiPolygon и внутренние дворы обходить все.
2. **Как рисовать.** Вертикальные окна нельзя нарисовать обычным
   `fill` — он лежит на земле. Каждое окно — тонкая `fill-extrusion`:
   footprint = прямоугольник окна, вынесенный на 0.06–0.10 м наружу от
   стены, `fill-extrusion-base` = низ окна, `fill-extrusion-height` =
   верх окна. Высота/база — из свойств фичи. Так окно реально стоит на
   фасаде и не мерцает с ним (z-fighting).
3. **Свет.**
   - Ночь: 45–55% окон горят; яркость и цвет — янтарь
     `#ffc978`…`#ffd79a` с разбросом; остальные — тёмно-синее
     `#16263c`…`#1b2e4a`. Рисунок кластерный (2–3 соседних окна —
     одна квартира), не шахматка.
   - День: все окна кремовые `#f2e3c8`…`#ffe9c9`, без свечения.
   - Ореол ночью: второй слой тех же окон, увеличенных на 15–25%,
     opacity 0.10–0.15, без blur-фильтра. Днём ореола нет.
4. **Поведение.**
   - Слой виден только при zoom ≥15.4; ниже — скрыт, как обычные окна.
   - При смене выбранного дома и темы слой перестраивается; старый
     источник/слой удаляется, без утечек и «призраков».
   - Клики по карте не перехватывать: выбор дома работает как сейчас.
   - Слой выше `buildings`, ниже подписей и маршрутов/зон.
5. **Производительность.** Не больше ~2 000 оконных полигонов (с
   ореолом); при превышении — реже шаг, а не больше полигонов.
   Fps не хуже: медиана ≤17.5 мс, кадров >33 мс ≤10 из 200.

## Критерий приёмки

На z16.6 и z18 выбранный дом выглядит как настоящий дом с окнами:
ряды совпадают с этажами, окна не «плавают», часть горит тёплым,
часть тёмная, есть мягкий ореол; у соседних домов — единичные огни.
Днём окна кремовые и не светятся. При смене дома не остаётся старых
окон и нет просадки fps. Данные не тронуты. Таймбокс — 80 минут:
если геометрия из тайлов не даётся — отчёт с точной причиной, без
подмены выдуманной геометрией.
