## Что уже есть (не ломать)

- Окна: flat <15.4, coarse 15.4–17, fine ≥17; выбор дома ведёт на 16.6.
- Зоны и маршруты интерполируются по зуму (V4a) — не трогать.
- Свет: `MAP_LIGHT` (anchor `viewport`, color `#fff1dc`, intensity 0.6,
  position `[1.5, 245, 46]`). Тела домов — `fill-extrusion` с
  `vertical-gradient: true`, крыши — отдельный roof-cap слой.
- CSS: `.map-grade` (saturate/contrast) и `.map-vignette` (radial gradient).
- MapLibre 6.17.0: **отдельного `fog` и `setFog` нет.** Дымка — это sky
  layer (`setSky`/`SkySpecification`: `sky-color`, `horizon-color`,
  `fog-color`, `fog-ground-blend`, `horizon-fog-blend`, `sky-horizon-blend`,
  `atmosphere-blend`) плюс CSS-градиент. Не изобретать несуществующий API.

## Задачи

### 1. Дымка к горизонту (обе темы)
- Добавить sky layer (если ещё нет) с палитрой под тему: день — молочный
  горизонт (`fog-color` около `#e3ebf4`), ночь — глубокий синий
  (`#1c2738`), без чёрного.
- `atmosphere-blend` связать с наклоном камеры (на pitch 55 — 0.25–0.40),
  чтобы дымка появлялась у горизонта, а не затягивала экран.
- Дополнить `.map-haze` — узкий CSS-градиент сверху (60–90 px, 0 → 0.35
  цвета тумана), `pointer-events: none`, под панелями UI.
- Критерий: дальние кварталы на 15.35 теряют ~10–15% контраста, ближние —
  нет; нет полосы-шва; карточка, чипы и поиск не задеты.

### 2. Псевдо-DOF (дешёвый)
- Центральный овал без размытия, к краям — до 1.5–2 px. Реализация:
  `backdrop-filter: blur(1.5px)` + `mask-image` (`-webkit-mask-image`),
  либо только градиентная мягкость, если blur стоит больше ~1 мс на кадр.
- Только ширина ≥768 px; на телефоне не включаем.
- Критерий: центр резкий, края мягкие; fps не хуже (медиана ≤17.5 мс,
  >33 мс ≤10 из 200); UI не размывается.

### 3. Разнообразие крыш
- Сейчас roof-cap — один тон на все дома. Детерминированная вариация по
  `id`: 3 оттенка в пределах ±3–4% светлоты, чуть тёплый / чуть холодный,
  без «радуги». Акцентная крыша выбранного дома (V2.1) сохраняется.
- Критерий: на 15.35 кварталы читаются как разные дома, а не плита;
  пять ступеней балла по-прежнему различаются.

### 4. Теневые фасады
- Жалоба: теневые грани почти чёрные. Поднять заполняющий свет:
  intensity 0.6 → 0.75–0.85, цвет чуть менее тёплый (`#fff6ea`), либо
  задать минимальную светлоту теневой грани.
- Критерий: светлая тема — теневые фасады не темнее ~35% светлоты,
  тёмная — не темнее ~18%; грани различаются, «чёрных стен» нет.

### 5. Контур выделенного дома на z18
- Уменьшить line-width 2.6 → 1.8 и opacity на z ≥ 17.5, ореол оставить.
- Критерий: выделение видно, но не «обведено маркером».
