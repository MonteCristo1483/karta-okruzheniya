# Задача Perf-2: красные зоны по видимым районам и по зумам

Дата: 2026-11-24. **Модель: DeepSeek V4.1 Flash.**
Полоса: `web/app/map.tsx`. Данные, тайлы, пайплайн не трогать.

## Контекст (измерено на устройстве владельца)

- z9.57, здания скрыты: **9 FPS, p95 566 мс**;
- z14.05: 19 FPS, p95 200 мс; z16.6: 27 FPS, p95 117 мс.

Причина обзорного провала: при старте грузятся `redzones.geojson` **всех 132
районов** (`Promise.all(districts.map(...))`), сливаются в один источник —
**35 801 линейный объект** по городу — и рисуются с `line-blur`,
интерполированным по зуму. На обзоре это вся красная сеть Москвы с blur.

POI уже переведены на загрузку видимых районов; красные зоны — последнее
место с массовой загрузкой.

## Что сделать

1. **Загрузка по видимым районам.** Заменить массовую загрузку на тот же
   механизм, что у POI: bbox из манифеста, кэш в памяти, не больше 16
   районов за обновление, приоритет — площадь пересечения с кадром. При
   выборе дома район дома догружается.
2. **Плотность по зумам** (правило):
   - z < 11 — красные зоны не показываем;
   - z 11–12 — только `trunk` (магистрали) и `railway`;
   - z 13+ — все классы, как сейчас.
3. **Размытие только вблизи.** `line-blur` оставить только с z ≥ 15;
   ниже — простая линия без blur (blur дорогой, а на обзоре не читается).
4. **Паритет z16.6** — цвета, толщины, blur как сейчас.
5. В `?perf=1` добавить число объектов красных зон в источнике (для контроля).

## Что нельзя

- Менять данные, тайлы, пайплайн, POI-правила, карточку, скоринг.
- Менять внешний вид красных зон на z16.6.
- Добавлять зависимости.

## Проверка

- `tsc`, build, e2e.
- Сетевой лог: на старте не 132, а ≤16 `redzones.geojson`; при движении —
  только новые районы; повторное движение — 0.
- На z9.6 с включёнными красными зонами FPS/p95 близки к варианту «зоны
  выключены» (в отчёте — оба замера, `?perf=1`).
- Кадры: z9.6 (зон нет), z12 (только магистрали/ж-д), z16.6 (паритет) —
  DPR 1, light.

## Критерий приёмки

1. Старт с красными зонами не грузит все 132 файла.
2. На z9.6 зон нет; на z12 — только trunk/railway; на z16.6 — как раньше.
3. FPS на z9.6 с зонами ≥ FPS без зон минус 20%.
4. `tsc`, build, e2e; дифф только в `web/app/map.tsx`.

## Стоп-условия

- На z14–15 без blur зоны перестают читаться — вернуть blur с z14, одна
  поправка, потом стоп.
- Нужны правки данных — стоп.
- 60 минут.
