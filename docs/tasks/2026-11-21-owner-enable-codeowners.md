# Действие владельца: включить Code Owner review для `main`

**Статус:** владелец подтвердил выполнение 21.11.2026.

Это одноразовый bootstrap для безопасной остановки auto-merge web/workflow PR.
В репозитории уже будет `.github/CODEOWNERS`; пока правило GitHub не включено,
одна только эта таблица никого не блокирует.

## Что включить

В GitHub: `Settings` → `Branches` / `Rulesets` → правило для ветки `main`.

Минимальные настройки:

1. Требовать pull request перед merge.
2. Требовать **1 approval**.
3. Требовать approval от **Code Owner**.
4. Сбрасывать старые approvals после новых коммитов.
5. Запретить bypass этого правила, включая администраторов.

Не выбирать несуществующий required check наугад. Точное имя проверок
добавить после реализации gate и подтверждения их на PR.

## Как понять, что готово

- Правило применяется именно к `main` и включено, а не в режиме Evaluate.
- В настройке виден Code Owner review и запрет обхода.
- После этого hub передаст gate-бриф исполнителю. До этого workflow-код не
  пушить: текущий Autopilot запускается из push-ветки и имеет write-права.

Это изменение настроек выполняет владелец; агент не входит в его аккаунт.
