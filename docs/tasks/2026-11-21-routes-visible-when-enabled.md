# Задача P1: показывать маршруты при активном слое

> **ОТКЛОНЕНО владельцем 21.11.** Маршруты показываются только при
> выбранном доме — это задумано. Иначе вся карта засвечена маршрутами.
> Не выполнять. Слой «Маршруты» без выбора дома работает как переключатель
> для выбранного дома, а не как общий слой. Отдельные вопросы по маршрутам
> владелец разберёт позже.

**Рекомендуемая модель:** DeepSeek V4.1 Flash.
**Зависимость:** выполнять после merge UX acceptance gate.

## Воспроизведение

- Прод: `?building=64091236` — Тверской бульвар, 3/1.
- Свежие WebKit-кадры 21.11.2026: `prod-sel-166-routes-{light,dark}-1290-dpr1.png`
  в `C:\Users\starg\AppData\Local\Temp\opencode\pw\shots-ref-matrix-2026-11-21\`.
- При `Маршруты` включён (`aria-pressed=true`) POI-плашки/минуты есть,
  но линии маршрутов не видны. Матрица:
  `docs/research/visual-reference-matrix-2026-11-21.md`.

## Цель

Найти причину и исправить отображение существующих пешеходных маршрутов
выбранного дома при ручном включении слоя. Не менять default auto-on/off —
это отдельное решение владельца.

## Проверить

1. Наличие/формат записей `routes/<id>.json` для этого здания и фактический
   результат загрузки; не печатать полный файл в отчёт.
2. `aria-pressed`, состояние видимости слоя, source/filter/zoom conditions,
   layer ordering и соответствие ID выбранного дома.
3. Повторить в обеих темах; проверить второй дом и смену выбора, чтобы
   исключить случайный stale-source/feature-state.
4. Если причина не в коде, а в маршрутах/геометрии, остановиться и описать
   evidence; данные не менять.

## Ограничения

- Только маршруты/их отображение; карточку не менять.
- Не менять данные, scoring, формулу, пять ступеней индекса или default
  включения слоя.
- Не генерировать линии/буферы «на глаз», не добавлять запросы к внешним API.

## Критерий приёмки

- В light и dark при активном чипе виден маршрут выбранного дома к POI на
  z16.6; при выключении линии исчезают.
- При смене дома старые линии не остаются; при отсутствии route data UI не
  рисует фиктивную линию и не падает.
- WebKit-скриншоты desktop/mobile, `tsc`, build и e2e зелёные.
- Поведение default auto-on/off не изменено; в отчёте указан корень проблемы
  и IDs проверенных домов.
