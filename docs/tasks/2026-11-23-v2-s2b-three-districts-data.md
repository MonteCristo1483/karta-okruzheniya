# Задача V2-S2b: данные трёх районов готовы

Дата: 2026-11-23. Исполнитель: pipeline-исполнитель (механика).
**Модель: DeepSeek V4.1 Flash (`opencode-go/deepseek-v4.1-flash`).**
Полоса: `pipeline/` и `data/` (локально). **`web/`, `.github/`, ветку `data`
не трогать.**

## Контекст

Шаг 2a (#163) принят: шарды, колоночный индекс, PMTiles подложки, манифест.
У Пресни маршруты и изохроны есть (1 696 жилых), у Тверского — 6 файлов,
у Арбата — 0. Для публикации трёх районов данные нужно доделать.

Найдено на приёмке: в `index.json.gz` **6 дублей** id — дома на границе
районов попали из двух district-артефактов (3 585 строк, 3 579 уникальных).

## Что сделать

### 1. Убрать дубли

`build_index.py` должен дедуплицировать по `osm_id` (оставлять первое
вхождение) и писать в отчёт число отброшенных дублей. Тот же дедуп — в
манифесте, если он перечисляет одни и те же файлы дважды.

### 2. Маршруты и изохроны для Тверского и Арбата

Только `is_home` (1 380 + 509 домов), тем же Valhalla, что и Пресня:

```powershell
docker run -d --name valhalla-svc -v "${PWD}/data/processed/valhalla:/custom_files" `
  -p 8002:8002 ghcr.io/valhalla/valhalla:latest valhalla_service /custom_files/valhalla.json
pipeline/.venv/Scripts/python.exe pipeline/routes_valhalla.py --district 1257786
pipeline/.venv/Scripts/python.exe pipeline/routes_valhalla.py --district 1257484
pipeline/.venv/Scripts/python.exe pipeline/isochrones_valhalla.py --district 1257786
pipeline/.venv/Scripts/python.exe pipeline/isochrones_valhalla.py --district 1257484
```

Если скрипты не принимают `--district` — добавить параметр, не меняя логику
и не трогая уже посчитанные файлы Пресни. Считать в фоне, батч резюмируемый:
повторный запуск не должен пересчитывать готовое.

### 3. Пересобрать пакеты

Прогнать `pack_district.py` для трёх районов, затем `build_index.py` и
`build_manifest.py`. Новые файлы — в том же формате, что принят в 2a.
Исходные `web/public/data/routes|isochrones` не менять.

## Проверка

- В индексе ровно **3 585 уникальных** id (Пресня 1 696 + Тверской 1 380 +
  Арбат 509), дублей 0.
- Покрытие маршрутами: у каждого жилого 5 направлений; если Valhalla не
  нашёл путь — записать id в отчёт (ожидаемо единицы), не выдумывать.
- Изохрона есть у каждого жилого или зафиксирован отказ.
- Round-trip шардов 20/20 по каждому району; sha256 манифеста сходится.
- 60 тестов зелёные; `web/` и `config/` без диффа.

## Что нельзя

- Менять `config/scoring.json`, `config/buildings.json`, правило `is_home`.
- Трогать `web/`, `.github/workflows`, ветку `data`, прод, Release.
- Пересчитывать Пресню, если файлы уже есть (только проверить).
- Коммитить `data/`, `*.gz`, `*.pmtiles`, `*.geojson`.
- Добавлять зависимости.

## Стоп-условия

- Valhalla не поднимается за 15 минут — стоп, отчёт (не искать обходные пути).
- Покрытие маршрутами ниже 95% — стоп, отчёт с причинами.
- Больше 8 изменённых файлов или 120 минут — стоп.

## Отчёт (≤40 строк)

1. PR, commit, diffstat.
2. Таблица: район / жилых / маршрутов / изохрон / отказов / размеры пакетов.
3. Дубли: сколько было, сколько осталось.
4. Round-trip и sha256: сколько проверено / совпало.
5. Риски одной строкой. Не начинать веб, деплой и полный прогон.
