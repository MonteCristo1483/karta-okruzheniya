# Задача: поэлементная карта визуальных референсов карты

**Режим:** визуальный аудит, read-only. Код, стили и карточку не менять.
**Рекомендуемая модель:** Gemini 4 Argon, High.

## Цель

Сравнить production-карту с тремя целевыми референсами владельца:
`design/card-dark-neon.png`, `design/card-diorama-day.png`,
`design/card-diorama-evening.png`. Не превращать сходство с рендером в
безусловную копию UI: карточку сейчас оставляем как есть.

## Проверка

- Снять production-карту в обеих темах: обзор 15.35 и выбранный дом 16.6,
  desktop 1290×900 DPR1 и mobile 390×844 DPR2. Для окон при необходимости
  добавить крупный кадр z18.
- Сопоставить только карту/сцену: земля, небо/горизонт, вода, зелень,
  здания/крыши/фасады, свет, маршруты, POI, красные зоны, слои и их подписи.
- Отдельно пометить элементы из `card-dark-neon`, для которых нужно решение:
  HUD-сетки/обводки, яркие неоновые эффекты и продуктовые подписи.
- Карточку, её композицию, кнопки, тексты и типографику не оценивать как
  задачу реализации; зафиксировать только, что они отложены владельцем.

## Формат результата

Таблица: элемент → референс → production сейчас → конкретный разрыв →
предлагаемый минимальный следующий шаг → влияние на читаемость/performance →
нужен ли выбор владельца.

Обязательно вынести конфликты SPEC:

- «Подводные камни» → разрешённый термин «Главные минусы»;
- «Оценка локации» → «Индекс окружения»;
- «Отправить клиенту» относится к B2B-функции вне текущего B2C MVP.

Не предлагать переносить эти тексты без отдельного изменения SPEC владельцем.
Числа в макетах считать иллюстративными; формулу и данные не менять.

## Критерий приёмки

Есть сравнимые кадры и таблица разрывов, все неясные элементы помечены как
вопрос владельцу. Карточка явно вне текущего скоупа. Никаких изменений
репозитория, кроме отчёта/предложения для хаба; никаких кодовых PR.
