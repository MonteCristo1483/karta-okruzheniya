# Задача E1: смоук-тесты интерфейса в Deploy

Дата: 2026-11-20. Страховка перед визуалом V2/V3. Только тесты и CI,
продуктовый код не меняем (кроме `data-testid`, если без них нельзя).

## Зачем
У нас 60 Python-тестов и ноль проверок интерфейса. Визуал переделывается
постоянно, «зелёный Deploy» ничего не говорит о том, что сайт открывается
и кнопки работают. Нужен минимальный, но стабильный набор.

## Где гонять
**В Deploy, между `Generate share pages` и `Publish to gh-pages`.** Там уже
развёрнуты настоящие данные; в `ci.yml` данных нет, приложение показывает
ошибку загрузки, и тесты были бы ложными.
Локальный запуск — против того же статического экспорта через
`scripts/serve-test.mjs`.

## Задача
1. `web/e2e/` + `playwright.config.ts`:
   - проект **chromium**, headless, `baseURL` из переменной;
   - 4 теста, **не зависящие от WebGL/карты**:
     a. **Boot**: страница открывается, есть поиск и 7 чипов слоёв, нет
        баннера `fatal`;
     b. **Тема**: клик по кнопке темы меняет `data-theme` на `dark`,
        после перезагрузки тема сохраняется (localStorage);
     c. **Слои**: клик по чипу «Маршруты» переключает `checked`, повторный
        клик возвращает; остальные чипы на месте;
     d. **Страницы `/r/`**: `GET /r/<id>/` отдаёт 200 и содержит адрес
        (3 разных id, включая `64091236`).
2. `npm run e2e` — поднимает `serve-test.mjs`, ждёт порт, гоняет Playwright,
   гасит сервер, код возврата пробрасывает.
3. В `deploy.yml` — шаг `Smoke tests` перед публикацией:
   `npx playwright install --with-deps chromium` (кэш
   `~/.cache/ms-playwright` по версии playwright), затем `npm run e2e`.
   Падение тестов **останавливает** публикацию (старый сайт остаётся жить).
4. `playwright` — devDependency точной версии (без `^`/`~`), lock обновить.
5. Если для селекторов нужны `data-testid` — добавить точечно (не менять
   внешний вид и тексты).

## Что нельзя
- Менять данные, `config/scoring.json`, `pipeline/`, визуал и логику карты.
- Тянуть тяжёлые фреймворки поверх Playwright (Cypress, Storybook и т.п.).
- Гонять тесты в `ci.yml` без данных.
- main/gh-pages, force-push, `npm run deploy`.
