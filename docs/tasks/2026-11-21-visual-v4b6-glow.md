# Задача V4b6: ночное свечение у основания выбранного дома

Дата: 2026-11-21. Запрос владельца: вернуть сильную неоново-зелёную
подсветку в ночном режиме — она была красивой. Не заливать стены зелёным:
свет должен жить **внизу**, у основания дома и на земле вокруг, как в
`design/card-dark-neon.png`.

## Что есть сейчас

- `glow-outer` / `glow-inner` + `outline-halo` по footprint; суммарная
  непрозрачность: день 0.10–0.12, ночь 0.20–0.25. Владельцу слабо.
- Контур крыши тонкий (1.5 px) — его не трогаем.

## Задача

### 1. Свет на земле вокруг дома (главное)
- 3 концентрических обводки по footprint выбранного дома, **на земле**,
  под зданиями:
  - ширина 14 / 34 / 72 px на z16.6, `line-blur` 8 / 20 / 40, цвет
    `#2ee6a0`, opacity 0.34 / 0.20 / 0.10;
  - ширина и прозрачность интерполируются по зуму: на 15.4 — ×0.8,
    на 18 — ×1.3; не «худеют» при приближении.
- Яркое ядро по краю footprint: ширина 2–2.5 px, цвет `#7dffcf`,
  opacity 0.5, без blur — оно даёт «неоновую» кромку.
- Всё это — только тёмная тема. В светлой — максимум 0.05–0.08, чтобы
  не спорить с диорамой.

### 2. Подсветка нижней части стен
- Отдельный слой: footprint дома, `fill-extrusion-base = 0`,
  `fill-extrusion-height = 0.6–0.9 м`, цвет `#2ee6a0`,
  `fill-extrusion-opacity = 0.16–0.20`, поверх зданий.
- Эффект: нижний пояс стен ловит зелёный свет, выше — обычный фасад.
  Стены целиком зелёными не делать.
- Только тёмная тема; в светлой слой скрыт.

### 3. Порядок и поведение
- Земляное свечение — под `buildings`; подсветка низа стен — над
  `buildings`, но под маршрутами, зонами, подписями и карточкой.
- При смене выбранного дома / сбросе выбора — переезжает вместе с
  контуром; при зуме <15.4 — скрыто вместе с окнами.
- Клики не перехватывать.

## Чего не делать

- Не заливать тело дома зелёным и не возвращать 16 px неон по всему
  объёму — только низ и земля.
- Не менять палитру ступеней, данные, scoring, карточку.
- Не трогать hero-окна (V4b4/V4b6-окна — отдельно) и контур крыши.

## Проверка

WebKit, **DPR 1 и DPR 2**: 1290×900 и 390×844, z16.6 и z18, тёмная и
светлая. Сравнить с `design/card-dark-neon.png`. Fps не хуже: медиана
≤17.5 мс (Chrome с GPU) — на headless WebKit абсолютные числа не
показатель, смотреть A/B. `tsc`, `npm run build`, `npm run e2e`.

## Критерий приёмки

В тёмной теме выбранный дом «стоит в зелёном свете»: яркая кромка по
контуру, мягкое свечение на земле и подсвеченный низ стен; стены выше
пояса — обычные. В светлой теме — едва заметно. Свечение не «худеет»
при зуме, не перекрывает маршруты и подписи. Таймбокс — 35 минут.
