# Подзадача PERF-3-TILECACHE: убрать обрывы тайлов и мигание подписей при резком скролле

Дата: 2026-11-25. **Модель: DeepSeek V4.1 Flash (`opencode-go/deepseek-v4.1-flash#high`).**
Полоса: только `web/app/map.tsx` (строки `~3100–3140`, `~3450–3545`).

## Диагноз

1. В `new maplibregl.Map({ ... })` не задан `maxTileCacheSize`: по умолчанию MapLibre хранит слишком мало тайлов на источник. При наклоне `pitch 60°` в одном кадре ~30 тайлов, и при резком сдвиге камеры MapLibre выбрасывает из памяти родительские тайлы `z9–13` и соседние кварталы — из-за чего на новом квадрате `z14` до прихода тайла виден обрыв дороги/магистрали.
2. При движении камеры ниже/выше порога и во время скролла подписи улиц (`street-labels`) обновляются рывком через 120 мс после полной остановки (`moveend`).

## Что сделать в `web/app/map.tsx`

1. В `new maplibregl.Map({ ... })` добавить:
   - `maxTileCacheSize: 600`,
   - `maxTileCacheZoomLevels: 8`,
   - `cancelPendingTileRequestsWhileZooming: false`.
2. В `refreshBasemapDecorations` / `rebuildLabels`:
   - не очищать существующие `labelCandidates` во время движения на `z >= DECOR_MIN_ZOOM`;
   - уменьшить дебаунс `basemapDecorTimer` после `moveend` со `120 мс` до `40 мс`, чтобы подписи на новых улицах появлялись сразу по остановке без видимой паузы-вспышки.

- `tsc --noEmit`, `npm run build`, `npm run e2e`.
