# Подзадача PERF-1-FLY: убрать слайд-шоу при клике на дом (100 049 `setFeatureState`)

Дата: 2026-11-25. **Модель: DeepSeek V4.1 Flash (`opencode-go/deepseek-v4.1-flash#high`).**
Полоса: только `web/app/map.tsx` (строки `~2555–2600`, `~4194–4245`, `~4565–4585`).

## Диагноз

При клике на дом (`selectById` → `applySelection(false)`) и при снятии выделения (`deselect` → `applySelection()`):
1. На первом выборе и каждом `deselect` (`selectedId === null`) цикл `for (const id of idsToStyle)` (строки `4226–4241`) обходит `allIds` (**100 049 домов Москвы**) и вызывает `map.setFeatureState(...)` 100 049 раз подряд в синхронном цикле ради флага `inactive`, который **нигде в стилях не используется** (в стилях читается только `["feature-state", "selected"]`).
2. Первой строкой `applySelection(false)` сбрасывает `currentFacadeLod = null` и вызывает `syncFacades`, что через `map.setPaintProperty("buildings", "fill-extrusion-pattern", ...)` заставляет MapLibre пересобрать 3D-геометрию всех видимых тайлов зданий прямо в кадр старта `flyTo`.

## Что сделать в `web/app/map.tsx`

1. В `applySelection(activateSelected = true)` (строки `~4194–4244`):
   - Полностью удалить ветку с `idsToStyle`, `allIds` и `featureStateInitialized` (и удалить `allIds` на строках `~2556, 2596`).
   - Делать максимум **2 точечных вызова `map.setFeatureState`**:
     - если `appliedSelectedId !== null && appliedSelectedId !== selectedId`:
       `map.setFeatureState({ ...stateSource, id: appliedSelectedId }, { selected: false })`;
     - если `selectedId !== null`:
       `map.setFeatureState({ ...stateSource, id: selectedId }, { selected: Boolean(activateSelected) })`;
     - обновить `appliedSelectedId = activateSelected ? selectedId : null`.
   - Не сбрасывать `currentFacadeLod = null; currentNonHomeDim = null; syncFacades(...)` при `activateSelected === false && map.isMoving()` (перед стартом `flyTo`): если нужно снять `selectedId` из `fill-extrusion-pattern` предыдущего дома — делать это только когда реально изменился `appliedSelectedId` или после остановки камеры (`activateSelected === true` / `selectedId === null`).
