# COMPETITOR — НедвижСкан (разбор 26.11.2026)

Единственный найденный сервис, продающий отчёт по конкретному адресу в Москве. Цена 250 ₽/объект, 469 ₽ за 3, безлимит 4 420 ₽/30 дней. Формат — PDF 9–12 стр., срок «до 1–5 мин». Исполнитель — самозанятый.

## Что они продают на самом деле

Не экологию, а **due diligence участка/квартиры по ЗОУИТ**. Блоки: вердикт + Risk Score 1–10 → карта зон с расстояниями → карточка объекта (ЕГРН/НСПД) → риски со ссылкой на норму → вода/септик → экология (воздух, роза ветров, радон) → **«аргументы для торга»** → протокол 11 источников.

Вывод для нас: платят не за «индекс», а за аргумент в переговорах и за доказательства. Это надо забрать в карточку (M1) и в отчёт (позже).

## Забрать как есть

1. **Каркас:** вердикт и балл на первом экране → факторы с нормой и статьёй → «чем это грозит/чем торговаться» → протокол источников с датой.
2. **Четыре честных статуса источника:** «получено / объектов нет / недоступен / не запрашивался». Прямо снимает риск «сказали чисто, а там свалка».
3. **Явный список «чего отчёт не заменяет»** — одновременно юридический щит и УТП (см. `docs/LEGAL-RISK.md`).
4. **Блог как вход из поиска:** одна статья = один запрос покупателя («год постройки по адресу», «как проверить ЗОУИТ»), таблица норм со ссылкой на первоисточник, дата обновления.

## Улучшить (наши преимущества)

| Их слабость | Наш ход |
|---|---|
| Веса Risk Score не опубликованы — балл невоспроизводим | формула в `config/scoring.json` + методика публично; вклад каждого фактора виден |
| Экология — растровая переаналитика (CAMS, километры), подаётся «по адресу» | честно: «фоновая оценка, не замер» + сравнение с соседними домами |
| Нет сравнения: нет «этот дом vs 5 соседних», нет перцентиля по району | сравнение — наша ось (M2), у них её нет |
| PDF-only, нет ссылки, нет свежести | мгновенная ссылка-открытка `?building=`, дата каждого слоя |
| Нулевое покрытие Москвы в SEO (11 страниц, ни одного района) | 132 районные страницы + адресные (M3) — трафик свободен |
| Нет блока «зелень» и «стройки рядом» | зелень по WHO 300 м/0,5 га (есть); стройки — из разрешений mos.ru (позже) |

## Не повторять

- **Радон цифрой** — они дают «оценку радоноопасности» без замера. Мы: «потенциал территории + закажите замер», без числа в балле.
- **Воздух как концентрация по адресу** — это ровно ошибка Яндекса; только фоновая полоса и вклад трассы.
- **Шум в дБА без модели** — у них «оценка фона»; мы не выдаём дБ, пока нет интенсивности потока.
- **Абсолютный балл без объяснения** — Risk Score 1–10 без весов; у нас каждый фактор объясним.

## Что это меняет в плане

- M1: карточка получает блок **«статус данных»** (получено/недоступно) и строку «чем это важно» — это дешёво и прямо копирует их сильнейший приём.
- M3: районные страницы + 10–15 статей-входов («год постройки по адресу», «ЗОУИТ рядом с домом») — их блог показывает, что модель работает.
- Цена: их 250 ₽ — доказательство готовности платить; наш бесплатный адресный вердикт = воронка, отчёты/подписка — позже.
