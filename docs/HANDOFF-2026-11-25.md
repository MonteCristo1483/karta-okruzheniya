## 6. Релиз и деплой (у владельца нет gh CLI)

Токен GitHub лежит в git credential. Схема:

1. Собрать `data.zip` из `data/` (Python zipfile, пути `data/...`).
2. Загрузить в Release с тегом `data` (API: создать/найти релиз, удалить старый
   ассет, `POST` на `upload_url?name=data.zip`). Авторизация:
   `git credential fill` → `password` → `Authorization: token ...`.
3. Влить кодовую ветку (autopilot сам) и запустить `deploy.yml`
   (`workflow_dispatch`, inputs `data_tag=data`, `data_ref=data`).
4. Проверить прод с cache-buster (`?x=random`), иначе CDN отдаст старое.

Старые архивы локально: `data.zip.pre-*` (для отката).
