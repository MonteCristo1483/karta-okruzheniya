# ROADMAP — стратегия и состояние (синк 13.11.2026)

Этот файл — точка входа для новой сессии. Читается первым, дальше
SPEC.md, PLAN.md, docs/decisions.md. Обновляется на каждом синке.

## Концепция (решено 13.11)

Продукт для ПОКУПАТЕЛЕЙ КВАРТИР (B2C): человек выбирает дом и видит
всё окружение — инфраструктуру, шум, магистрали, стройку, «подводные
камни». Риелторы и монетизация — НЕ сейчас. Деньги прикрутим позже
(баннеры/прочее), когда продуктом реально пользуются.

Два класса фич (важное разделение):
- **Окружение** (наш фокус): шум, дороги, ж/д, стройка, воздух, парки,
  школы, метро. Данные из OSM/data.mos.ru, пайплайн готов.
- **Сам дом** (тонкие стены, приоритетные этажи, качество ЖК): данных
  нет ни в одном открытом источнике. Только ручной контент/краудсорс.
  НЕ раньше v2, не смешивать с текущим фокусом.

Стиль: пастельная диорама (день/вечер) — основной; тёмная тема есть.
Неоновый HUD — только маркетинг (SPEC §4).

## География (решено 13.11)

Доводим формулу и UX на Пресненском районе. Масштабирование — только
после технического рубежа PMTiles (geojson 4 МБ/район не масштабируется).

## Состояние на 13.11

Работает: PWA на GitHub Pages, 3D-карта Пресни, выбор дома, шторка
со скорингом, слои, РЕАЛЬНЫЕ пешие маршруты Valhalla, публичная ссылка
на дом, тёмная тема. Скоринг v4: бонусы по времени маршрута,
ж/д платформы (МЦД) в транспорте. Эталон 21/30 (было 18/30).
Деплой: git worktree в gh-pages (npm run deploy ломается на тысячах
файлов, см. DEPLOY.md «Способ 1б»).

1. ~~Маршрут рисуется к POI выключенного слоя~~ — ИСПРАВЛЕНО 13.11

5. Разбивка в шторке: писать расстояние фактом («школа в 350 м»),
   POI выбирается ближайший по расстоянию (пока оставить).

## Эталон скоринга (честный статус)

Текущий reference_set.md — список от нейронки, грубый. Расхождения
модели с ним частично объясняются факторами вне модели (удалённость
от центра, пробки). ЗАДАЧА «Эталон-2»: глубокий разбор каждого района
(причины оценки, источники, можно агентами) — до него формулу не
крутить, 21/30 считать потолком текущей модели.

## Очередность (роадмап)

1. **FX-пакет**: баги 1–3 из бэклога — одна сессия.
2. **M8**: год постройки в шторку (data.mos.ru файл уже скачан).
3. **Изохроны 5/10/15** — оживить кнопки через Valhalla isochrone.
4. **Эталон-2** — глубокий анализ (параллельно, руками/агентами).
5. **PMTiles** — технический рубеж (перевод зданий/POI с geojson).
6. Масштаб: ЦАО+престижные районы → вся Москва.
7. Монетизация — когда есть пользователи.
