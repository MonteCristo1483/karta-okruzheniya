импорт T3–T7. Слои: вьюхи `buildings_presnya`, `poi_presnya`, `linear_presnya`.

Магазинов много (включая точечные), ок. Школ/садов всего 75 — против десятков
реальных учреждений района: часть зданий школ/садов есть в OSM как здания
(`building=school`), но без `amenity`, либо размечены только на data.mos.ru.
Подтянуть data.mos.ru (SPEC §5: «школы/сады точнее там»). Входов метро мало
(26) — часть входов не размечена нодами; для скоринга хватает ближайшей
станции, но проверить вручную.

В районе нет trunk (МКАД снаружи, Кутузовский — primary). Штраф «магистраль
−2.5» в районе фактически считается по primary и secondary — ок, но в конфиге
(SPEC §3) веса trunk ×1.0 / primary ×0.7 / secondary ×0.4.

## Выводы для человека

1. Адреса и высоты: ~четверть зданий без них — закрывается data.mos.ru /
   ГИС ЖКХ / Overture (самый слабый слой по SPEC §5 — стройки, их в районе
   почти нет: `landuse=construction` не проверялся, стоит добавить в T-задачу
   по данным при расширении).
2. Школы/сады: уточнить через data.mos.ru до скоринга T12, иначе бонусы
   «школы +1.0 / сады +0.5» занизятся.
3. Остальное (дороги, ж/д, метро) — достаточно для скоринга недели 2.
