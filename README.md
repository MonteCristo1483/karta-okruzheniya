# Карта окружения дома

Инструмент для людей, которые выбирают или снимают квартиру в Москве:
3D-карта, индекс окружения дома (0–10), пешие маршруты, красные зоны,
публичная ссылка на дом.

- SPEC.md — что строим, формула индекса, экраны, данные
- CLAUDE.md — стек и правила для ИИ-агента
- PLAN.md — задачи по неделям
- design/ — макеты (светлая/тёмная тема + концепты для видео)

Статус: работающий прототип по Пресненскому району (B2C-жилец).
