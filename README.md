# Карта окружения дома

Инструмент для риелторов: 3D-карта Москвы, индекс окружения дома (0–10),
пешие маршруты, красные зоны, отчёт клиенту одной ссылкой.

- SPEC.md — что строим, формула индекса, экраны, данные
- CLAUDE.md — стек и правила для ИИ-агента
- PLAN.md — задачи по неделям
- design/ — макеты (светлая/тёмная тема + концепты для видео)

Статус: подготовка к разработке (недели 0–2).
