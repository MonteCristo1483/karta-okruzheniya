# Эталонный набор (30 районов Москвы)

Неделя 0 · ручной. Как пользоваться: на T12 агент считает индекс для 1–2
контрольных домов на указанных улицах и сводит таблицу «вердикт vs индекс».
Расхождения = материал для подгонки config/scoring.json (правим только конфиг).

ВАЖНО: вердикт — про ЭКОЛОГИЮ/ТИШИНУ (субъективный, ваш).
Прогноз — про НАШУ ФОРМУЛУ (транспорт+школы+парки+магазины − магистраль/жд/стройка).
Формула и экология — разные вещи; разница между колонками и есть предмет калибровки.

## Как считать расхождение на T12

- Индекс в пределах прогноза → ок.
- Выше/ниже прогноза на 1.5+ → смотрим разбивку: какой фактор «виноват»
  (транспорт переоценён? магистраль недооценена?) → правим его вес в конфиге.
- Калибровка итерируется до совпадения на 25+ из 30 районов.
